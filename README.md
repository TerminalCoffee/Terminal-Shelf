# Documentação — Estante Virtual

Este diretório contém a documentação inicial do projeto.

## Estrutura

- `PRD.md` — produto, problema, objetivos, escopo e requisitos de alto nível.
- `ARCHITECTURE.md` — arquitetura atual e alvo, estruturada a partir de arc42.
- `ADR/` — decisões arquiteturais que explicam escolhas e suas consequências.

## Regra de fonte de verdade

- **O que e por quê do produto:** `PRD.md`
- **Como o sistema é estruturado hoje e para onde evolui:** `ARCHITECTURE.md`
- **Por que uma decisão arquitetural foi tomada:** `ADR/`

Evite duplicar a mesma decisão em múltiplos arquivos sem uma razão clara.
